# naive_proxy documentation

Documentation is split by intent so operator guidance, behavioural promises,
and maintenance procedures do not drift into duplicate descriptions.

| Area | Audience | Contents |
|---|---|---|
| [Guides](guides/README.md) | operators | task-oriented deployment and service examples |
| [Contracts](contracts/README.md) | operators, developers, reviewers | normative role behaviour with implementation and test evidence |
| [Maintenance](maintenance/README.md) | maintainers and agents | repeatable change, testing, version-update, and debugging runbooks |
| [Scripts](scripts/README.md) | production incident operators | optional HAProxy H2 capture, transfer, and analysis helpers |

The role-level [README](../README.md) is the normal operator/developer entry
point. [AGENTS.md](../AGENTS.md) contains only repository-local execution rules
and a map to the documents above.
